# 👑 החוקה של יאמין (עץ קישורים + אתר חוקה לדיסקורד)

אתר יוקרתי ומודרני בגווני זהב ושחור עבור **יאמין**, המשלב:
1. **עץ קישורים (Linktree)** - גישה מהירה לשרת הדיסקורד וערוץ ה-Kick.
2. **חוקת הרפובליקה** - כל חוקי השרת הרשמיים עם חיפוש מהיר ואפשרות אישור חוקה.
3. **חדר איסור הפצה** - פירוט מלא של כל התכנים שאסור להפיץ בשרת (דוקסינג, NSFW, קישורי פישינג, Gore וכו').

## 🚀 איך מפעילים את האתר במחשב?
פשוט לחצו לחיצה כפולה על הקובץ `index.html` והוא ייפתח מיידית בכל דפדפן!

---

## 🌐 איך להעלות את האתר לרשת (בחינם עם קישור אישי)?

### אופציה 1: Vercel / Netlify (הכי מהיר וקל)
1. גשו לאתר [Vercel.com](https://vercel.com) או [Netlify.com](https://netlify.com) והירשמו בחינם.
2. גררו את התיקייה `החוקה של יאמין` ישירות למסך.
3. תוך 5 שניות האתר יהיה באוויר עם כתובת אינטרנט ציבורית שתוכלו לשים בביו בכל מקום!

### אופציה 2: GitHub Pages
1. פתחו Repository ב-GitHub והעלו את הקבצים.
2. בהגדרות (Settings) -> בלשונית Pages -> בחרו ב-Branch `main` ולחצו Save.

---

## 🛠️ מבנה הקבצים
- `index.html` - מבנה האתר, הטאבים, הקישורים והחוקים.
- `style.css` - עיצוב הזהב היוקרתי, אפקטי תאורה ואנימציות.
- `script.js` - לוגיקת החיפוש, המעבר בין טאבים, העתקת קישורים ואפקט הניצוצות.
- `assets/logo.png` - תמונת הלוגו הרשמית.
